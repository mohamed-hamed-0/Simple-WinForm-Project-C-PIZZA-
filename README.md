# Simple-WinForm-Project-C-PIZZA-
# 🍕 Pizza Ordering Desktop Application

A modern and interactive desktop application built using **C# Windows Forms (WinForms)** and **.NET**. This project provides a smooth user experience for customizing pizza orders with real-time price calculations and live order summaries.

---

## 🚀 Features

* **Dynamic Pricing:** Automatically calculates the total price in real-time based on the selected size, crust type, and toppings.
* **Live Order Summary:** Instantly updates order details (Size, Toppings, Crust, and Dine-in/Take-out method) as the user interacts with the UI.
* **Form Validation & Reset:** Full support for resetting all controls and validating order confirmation before submission.
* **Interactive UI:** Clean layout utilizing customized panels, radio buttons, and checkboxes.

---

## 🛠️ Technologies Used

* **Framework:** .NET / Windows Forms (WinForms)
